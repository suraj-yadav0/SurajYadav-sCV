# Suraj Yadav - Curriculum Vitae

Personal engineering resume written in LaTeX, automated with GitHub Actions to compile and deploy to GitHub Pages on every push.

- Live PDF: [suraj-yadav0.github.io/SurajYadav-sCV/cv.pdf](https://suraj-yadav0.github.io/SurajYadav-sCV/cv.pdf)
- Portfolio: [suraj-yadav0.github.io/portfolio-v4](https://suraj-yadav0.github.io/portfolio-v4/)

## Building Locally

To compile the PDF locally with TeX Live:

```bash
make
```

Or run pdflatex directly:

```bash
pdflatex cv.tex
```

To clean build artifacts:

```bash
make clean
```
